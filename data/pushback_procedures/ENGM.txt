# ENGM Oslo/Gardermoen - default pushback procedures
#
# Source: AIP Norway (Avinor), ENGM AD 2.20 "Local aerodrome regulations"
# para 8 (Pushback), and the AD 2.24 charts "Aircraft Parking/Docking Chart -
# Civil terminal area West / East / Coordinates", AIRAC 2026-11-26.
# For flight simulation only - not for real-world operations.
#
# How the numbers were derived:
# - Stand positions from the AIP stand coordinates; stand headings from the
#   lead-in lines on the parking/docking charts (or the heading of the stand
#   row where no lead-in line could be read).
# - Release point positions from the release point symbols on the charts
#   (symbol base = nosewheel), georeferenced with the stand coordinates (about
#   1-5 m accuracy). Headings from the taxiway centreline lights drawn through
#   the release point (the symbols themselves are only accurate to ~5 deg);
#   symbol direction where no straight light row could be fitted.
# - Distances are for the aircraft reference point, assuming it lies 13 m
#   behind the nosewheel (25 m for code D/E, 30 m for code F). Larger or
#   smaller aircraft end a few metres off; adjust in the planner if needed.
# - Release points ahead of the turned aircraft are reached with a forward
#   pull after the turn ("forward" step), as the charts place them.
# - Straight pushbacks (para 8.4): the AIP does not publish the push length;
#   45 m is an assumption. The turn direction after the push (para 8.7) is
#   given in the name; it is the pilot's turn when taxiing out.
# - Where ATC gives a choice of release points, each one is a separate entry.
